## Project Overview
Oulu Health Connect is a concept for a cross-platform mobile application designed to help international students and immigrants easily access healthcare services in Oulu, Finland. The application addresses the challenge of navigating an unfamiliar healthcare system by providing location-based healthcare information, emergency contacts, student health services, and educational resources through an intuitive mobile experience.

## Problem Statement
International students and immigrants often face difficulties in locating healthcare services due to language barriers and limited knowledge of the Finnish healthcare system. The project aimed to create a centralized digital platform that simplifies access to hospitals, pharmacies, laboratories, emergency services, and wellness resources while promoting healthcare awareness.

## Project Outcome
Developed a comprehensive application concept and technical design for a healthcare navigation platform that improves healthcare accessibility for international students in Oulu. The project demonstrated end-to-end software planning, including requirements analysis, technical architecture, user experience design, security planning, testing strategy, and risk management, resulting in a presentation-ready functional prototype concept.

## Core Features
- Interactive map showing hospitals, pharmacies, laboratories, and healthcare facilities
- Student healthcare service directory
- Emergency contact information with nearby healthcare locations
- Personalized user accounts and authentication
- Health articles and wellness resources
- Search functionality for healthcare services
- Navigation support using integrated maps
- Notifications for healthcare updates and reminders

## UX & Design
The application was designed with a user-centric approach focusing on simplicity, accessibility, and intuitive navigation. The project included wireframes and mockups for:
- Login & registration
- User profile management
- Healthcare directory
- Interactive maps
- Emergency services
- Mental wellness resources
- Student healthcare services
- Health education articles
