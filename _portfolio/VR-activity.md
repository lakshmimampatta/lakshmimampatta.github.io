## Overview
Developed a VR interaction prototype in Unity using the XR Interaction Toolkit and XR Device Simulator to design and test object interactions in a virtual environment without requiring physical VR hardware.

## Key Features
- Designed an interactive 3D virtual environment.
- Implemented object interaction mechanics using Unity's XR Interaction Toolkit.
- Used the XR Device Simulator to emulate VR headset and controller input during development.
- Built and tested interaction workflows in a simulated XR environment.

## Technologies
- Unity
- C#
- XR Interaction Toolkit
- XR Device Simulator
- Virtual Reality (VR)

## Skills Demonstrated
- Unity Development
- XR Prototyping
- Virtual Reality Development
- 3D Scene Design
